# Євген Січкар — лікар-дерматолог · Лендінг

Односторінковий сайт-візитка дерматолога з **календарем запису**: пацієнт обирає
вільний час, заявка приходить у **Telegram** і зберігається в **базі Postgres**,
а лікар бачить усе в **адмін-панелі** (`/admin`).

**Стек:** чистий HTML / CSS / JS + serverless-функції (Vercel) + Postgres
(Neon / Vercel Postgres / Supabase — будь-який) через драйвер `pg`.

## Структура

```
├── index.html                    # весь лендінг + форма з календарем
├── admin.html                    # адмін-панель (/admin)
├── styles.css                    # стилі
├── script.js                     # меню, анімації, календар, відправлення форми
├── api/
│   ├── lead.js                   # запис → Postgres + Telegram
│   ├── slots.js                  # які часи вже зайняті на дату
│   ├── admin.js                  # дані для адмінки (за логіном/паролем)
│   ├── health.js                 # діагностика підключень (/api/health)
│   ├── _config.js                # розклад прийому (дні, години, крок)
│   └── _db.js                    # підключення до Postgres
├── assets/
│   ├── doctor.jpg                # фото лікаря
│   └── doctor-placeholder.svg    # заглушка, поки фото немає
├── package.json                  # залежність pg
├── robots.txt
└── vercel.json
```

**Як працює запис:** пацієнт обирає день і вільний час → `/api/lead` перевіряє,
що слот не зайнятий → додає рядок у базу і шле сповіщення в Telegram.
Таблиця `bookings` створюється автоматично при першому запиті.

## 1. Додати фото

Покладіть своє фото у файл **`assets/doctor.jpg`** (вертикальне, приблизно 3:4,
бажано від 800px завширшки). Поки файлу немає — показується заглушка.

## 2. Створити Telegram-бота (5 хвилин)

1. Відкрийте в Telegram **[@BotFather](https://t.me/BotFather)** → команда `/newbot`.
2. Дайте боту ім'я (наприклад, `Запис до дерматолога`) і username (наприклад, `sichkar_derm_bot`).
3. BotFather видасть **токен** виду `123456789:AAE...xyz` — збережіть його.
4. **Важливо:** відкрийте свого нового бота і натисніть **Start** —
   інакше він не зможе писати вам повідомлення.
5. Дізнайтеся свій **chat_id**: напишіть боту **[@userinfobot](https://t.me/userinfobot)** —
   він відповість числом виду `123456789`.

## 3. Задеплоїти на Vercel і під'єднати базу

1. Зареєструйтесь на [vercel.com](https://vercel.com) через GitHub.
2. **Add New → Project** → оберіть цей репозиторій → Deploy.
3. **Створіть базу Postgres і під'єднайте її до проєкту:**
   вкладка **Storage → Create Database → Postgres (Neon)** → оберіть план
   **Free** → **Connect Project** → проєкт `dermo`.
   Vercel **сам** додасть у проєкт змінну `DATABASE_URL` (або `POSTGRES_URL`) —
   копіювати руками нічого не треба.
4. **Settings → Environment Variables** → додайте решту змінних:

   | Name             | Value                        |
   |------------------|------------------------------|
   | `TG_BOT_TOKEN`   | токен від BotFather          |
   | `TG_CHAT_ID`     | ваш chat_id від @userinfobot |
   | `ADMIN_LOGIN`    | логін для входу в /admin      |
   | `ADMIN_PASSWORD` | пароль для входу в /admin     |

5. **Deployments → ⋯ → Redeploy**, щоб змінні підхопилися.
6. Перевірте `https://ваш-сайт/api/health` — має бути `"dbReachable": true`.
   Потім оберіть час у календарі й запишіться: рядок з'явиться в базі та
   в адмінці, а сповіщення прийде в Telegram.

> Підійде будь-який Postgres (Neon, Supabase, Railway…). Головне — щоб у
> проєкті була змінна `DATABASE_URL` з рядком підключення. Для безкоштовних
> баз бажано брати **pooled**-рядок (з'єднання через пул).

## Адмін-панель (`/admin`)

Відкрийте `https://ваш-сайт/admin`, увійдіть за `ADMIN_LOGIN` / `ADMIN_PASSWORD`:

- **Записи** — майбутні записи, згруповані за днями (зручно планувати прийом);
  кожен запис можна **редагувати** (✏️ — ім'я, телефон, дату, час, статус) або
  **видалити** (🗑).
- **Усі заявки** — таблиця всіх заявок зі статусами й тими самими діями.
- Зверху — лічильники: усього / нових сьогодні / майбутні записи.

> ⚠️ **Безпека:** заявки містять телефони пацієнтів. Обов'язково задайте
> **надійний** `ADMIN_PASSWORD` (не `69`!). Якщо змінні не задані, за
> замовчуванням діють `67` / `69` — лише для першого тесту.

## Змінити розклад прийому

Дні, години та крок слота задані у **двох** місцях (тримайте однаковими):
`api/_config.js` (об'єкт `SCHEDULE`) і `script.js` (об'єкт `BOOKING`).

## Локальний перегляд

Просто відкрийте `index.html` у браузері, або:

```bash
npx serve .
```

> Форма локально працюватиме тільки через `vercel dev`
> (потрібні змінні оточення в файлі `.env`).

## Жива карта Google

У секції «Контакти» вже вбудована інтерактивна карта Google Maps із вашою міткою.
Щоб змінити локацію: у Google Maps відкрийте потрібну точку → **Поділитися** →
вкладка **«Вбудувати карту»** → скопіюйте `src="..."` з `<iframe>` і замініть
значення `src` у блоці `<iframe class="map__frame" ...>` в `index.html`.

## Що можна змінити

- **Тексти/відгуки** — прямо в `index.html`, все підписано коментарями по секціях.
- **Кольори** — CSS-змінні на початку `styles.css` (блок `:root`).
- **Телефон/Telegram** — пошук по `067` та `zhenya1771` в `index.html`.
