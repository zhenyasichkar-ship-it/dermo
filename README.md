# Євген Січкар — лікар-дерматолог · Лендінг

Односторінковий сайт-візитка дерматолога з формою запису на консультацію,
яка надсилає заявки в Telegram.

**Стек:** чистий HTML / CSS / JS + одна serverless-функція (Vercel) для Telegram.

## Структура

```
├── index.html                    # весь лендінг
├── admin.html                    # адмін-панель (/admin)
├── styles.css                    # стилі
├── script.js                     # меню, анімації, форма, підстановка налаштувань
├── api/
│   ├── lead.js                   # форма → Telegram + збереження в базу
│   ├── admin.js                  # захищені дії адмінки (заявки, налаштування)
│   ├── settings.js               # публічні налаштування сайту
│   ├── _kv.js                    # хелпер бази Vercel KV
│   └── _settings.js              # поля налаштувань + значення за замовчуванням
├── assets/
│   ├── doctor.jpg                # фото лікаря
│   └── doctor-placeholder.svg    # заглушка, поки фото немає
├── robots.txt
└── vercel.json
```

## 1. Додати фото

Покладіть своє фото у файл **`assets/doctor.jpg`** (вертикальне, приблизно 3:4,
бажано від 800px завширшки). Поки файлу немає — показується заглушка.

## 2. Створити Telegram-бота (5 хвилин)

1. Відкрийте в Telegram **[@BotFather](https://t.me/BotFather)** → команда `/newbot`.
2. Дайте боту ім'я (наприклад, `Запис до дерматолога`) і username (наприклад, `sichkar_derm_bot`).
3. BotFather видасть **токен** виду `123456789:AAE...xyz` — збережіть його.
4. **Важливо:** відкрийте свого нового бота і натисніть **Start** —
   інакше він не зможе писати вам повідомлення.
5. Дізнайтеся свій **chat_id**: напишіть боту **[@userinfobot](https://t.me/userinfobot)** —
   він відповість числом виду `123456789`.

## 3. Задеплоїти на Vercel

1. Зареєструйтесь на [vercel.com](https://vercel.com) через GitHub.
2. **Add New → Project** → оберіть цей репозиторій → Deploy
   (налаштування збірки міняти не треба — це статичний сайт).
3. Після деплою: **Settings → Environment Variables** → додайте дві змінні:

   | Name           | Value                        |
   |----------------|------------------------------|
   | `TG_BOT_TOKEN` | токен від BotFather          |
   | `TG_CHAT_ID`   | ваш chat_id від @userinfobot |

4. **Deployments → ⋯ → Redeploy**, щоб змінні підхопилися.
5. Готово! Тестуйте форму — заявка має прийти вам у Telegram.

## Адмін-панель (`/admin`)

Захищена паролем сторінка для перегляду заявок і редагування контенту:

- **Заявки** — таблиця всіх записів (ім'я, телефон, повідомлення, дата),
  статуси «нова / опрацьовано», видалення. Заявки й далі дублюються в Telegram.
- **Налаштування** — телефон, Telegram, графік, вартість, підпис під картою.
  Зміни одразу застосовуються на сайті.

### Що потрібно налаштувати на Vercel

1. **База даних** — вкладка **Storage → Create Database → KV** (безкоштовно).
   Підключіть її до проєкту — Vercel сам додасть змінні `KV_REST_API_URL`
   та `KV_REST_API_TOKEN`.
2. **Пароль адмінки** — **Settings → Environment Variables** → додайте:

   | Name             | Value                          |
   |------------------|--------------------------------|
   | `ADMIN_PASSWORD` | ваш пароль для входу в /admin  |

3. **Redeploy** — щоб змінні підхопилися.
4. Відкрийте `https://ваш-сайт/admin`, введіть пароль — і користуйтесь.

> Без KV сайт і форма працюють як зазвичай, але список заявок буде порожнім
> (нема де зберігати). Telegram-сповіщення від KV не залежать.

## Локальний перегляд

Просто відкрийте `index.html` у браузері, або:

```bash
npx serve .
```

> Форма локально працюватиме тільки через `vercel dev`
> (потрібні змінні оточення в файлі `.env`).

## Жива карта Google

У секції «Контакти» вже вбудована інтерактивна карта Google Maps із вашою міткою.
Щоб змінити локацію: у Google Maps відкрийте потрібну точку → **Поділитися** →
вкладка **«Вбудувати карту»** → скопіюйте `src="..."` з `<iframe>` і замініть
значення `src` у блоці `<iframe class="map__frame" ...>` в `index.html`.

## Що можна змінити

- **Тексти/відгуки** — прямо в `index.html`, все підписано коментарями по секціях.
- **Кольори** — CSS-змінні на початку `styles.css` (блок `:root`).
- **Телефон/Telegram** — пошук по `067` та `zhenya1771` в `index.html`.
